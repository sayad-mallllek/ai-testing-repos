# Returns and exchanges

Trailhead Outfitters is a fictional outdoor gear store. Unused gear can be returned within 30 days of delivery. Return items must have their original tags, packaging and proof of purchase. Trying boots indoors on a clean floor is allowed, but boots worn outdoors are considered used and do not qualify for the unused-item return policy. Refunds go to the original payment method within five business days after inspection. Customers pay return shipping unless the store sent the wrong item or the item arrived damaged. Contact the store before shipping anything back so the return can be matched to the order reference.

Size exchanges follow the same 30 day deadline and unused condition requirement. An exchange depends on stock availability; a tool must check the current inventory before promising a replacement. Clearance items follow the same unused-item policy unless the product listing explicitly states final sale. A manufacturing defect is handled through the warranty policy rather than by extending the unused-item return window. Keep your order reference and describe the issue clearly when requesting help. This guide describes dummy store rules for learning and does not establish a real merchant agreement.
